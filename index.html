NTU COOL 工具包隱私權政策

最後更新：2026 年 9 月 5 日

本擴充功能用於協助獲授權的 NTU COOL 支援與課程管理人員，查詢、整理與批次處理課程成員及班別資料。本政策說明擴充功能如何處理資料。

1. 處理的資料

在使用者開啟相關功能時，擴充功能可能會讀取當前 NTU COOL 頁面及同一網域 API 回應中的：

  • 課程網址、課程 ID、課程名稱與頁面類型；
  • 成員姓名、電子郵件、使用者 ID、身分、註冊狀態與班別；
  • 使用者主動貼上的姓名、信箱、課程網址或課程 ID；
  • 功能開關、批次處理間隔與每批數量等偏好。

擴充功能使用瀏覽器已有的 NTU COOL 登入狀態發出同網域 HTTPS 請求，但不讀取或儲存密碼、驗證 cookie 或其他登入憑證。

2. 資料用途

上述資料僅用於擴充功能的用戶可見功能，包含名冊、搜尋、統計、複製、預覽、班別調整、成員移除及使用者指示的批次開啟。不用於廣告、行銷、追蹤、個人化推薦、信用評分或與擴充功能無關的目的。

3. 儲存與保留

課程、成員、姓名、信箱與輸入名單只在擴充功能介面運作期間處理，不會儲存至發布者或第三方伺服器。功能開關與批次處理偏好儲存在 chrome.storage.sync，可能依使用者的 Chrome 同步設定由 Google 同步到其他裝置。移除擴充功能後，這些偏好可由 Chrome 一併刪除。

4. 傳輸、分享與販售

擴充功能只與獲授權的 NTU COOL 服務網域以 HTTPS 交換功能所需資料。擴充功能沒有發布者伺服器、第三方分析服務或廣告服務，不會將使用者資料出售、分享或轉移給第三方。

5. 安全與使用者責任

所有受支援的網域均使用 HTTPS。擴充功能不會擴大使用者在 NTU COOL 的原有權限；每項操作仍受目前帳號權限限制。使用者應僅在已獲授權管理的課程中使用本工具，並在執行寫入或移除操作前確認預覽內容。

6. Limited Use

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

7. 政策更新與聯絡

如資料處理方式發生變更，發布者會先更新商店頁面、本政策，並依規定在擴充功能中提供顯著通知。如有隱私權問題，請透過 Chrome 線上應用程式商店商品頁所列的發布者聯絡方式聯絡。
