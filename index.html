NTU COOL 工具包隱私權政策

最後更新：2026 年 10 月 7 日

本擴充功能用於協助獲授權的 NTU COOL 支援與課程管理人員，查詢、整理與批次處理課程成員及班別資料。本政策說明擴充功能如何處理資料。

1. 處理的資料

在使用者開啟相關功能時，擴充功能可能會讀取當前 NTU COOL 頁面及同一網域 API 回應中的：

  • 課程網址、課程 ID、課程 SIS ID、課程名稱、學期與頁面類型；
  • 目前登入者可見的帳號 ID、父層帳號 ID 與管理員角色狀態；
  • 成員姓名、電子郵件、使用者 ID、身分、註冊狀態與班別；
  • 管理員下載完整名冊時，另讀取成員的登入帳號、SIS ID、所有登入帳號與登入方式、是否曾合併帳號、加入課程的時間，以及在該課程的最後活動時間與累積活動時間；
  • 使用者主動貼上的姓名、信箱、課程網址、課程 ID、課程名稱或課程 SIS ID；
  • 功能開關、批次處理間隔與每批數量等偏好。

擴充功能使用瀏覽器已有的 NTU COOL 登入狀態發出同網域 HTTPS 請求，但不讀取或儲存密碼、驗證 cookie 或其他登入憑證。

2. 資料用途

帳號 ID 與管理員角色狀態只用於確認目前有效身分是否為任一 NTU COOL 帳號或子帳號的管理員。通過驗證後，其他資料僅用於擴充功能的用戶可見功能，包含名冊、成員與課程搜尋、統計、複製、下載完整名冊、預覽、班別調整、成員移除及使用者指示的批次開啟。不用於廣告、行銷、追蹤、個人化推薦、信用評分或與擴充功能無關的目的。

3. 儲存與保留

課程、班別與成員資料只在使用者的 Chrome 與 NTU COOL 之間處理，不會傳送至發布者或第三方伺服器。功能開關與批次處理偏好儲存在 chrome.storage.sync，可能依使用者的 Chrome 同步設定由 Google 同步到其他裝置。

管理員驗證的帳號與角色結果只在當前 NTU COOL 分頁的記憶體中短暫快取，不會寫入 chrome.storage.sync 或 chrome.storage.local。

選用的「作為使用者」功能（預設關閉）會把最近作為的使用者的 ID、姓名、身分與課程 ID 暫存在 chrome.storage.session；開啟此功能的管理員開啟課程成員頁時，也會以唯讀方式取得該課程的成員名單（使用者 ID、姓名、身分，以及臺大帳號的學號部分；不含校外人士的電子郵件），暫存於同一儲存區，供作為其他使用者時搜尋切換，只保留最後一門課程的名單。此資料只保留在目前瀏覽器工作階段的記憶體中，關閉瀏覽器即清除，不會寫入磁碟、不使用同步儲存，也不會傳送給發布者或第三方。

為了在批次移除中斷後清楚列出已執行與未執行成員，擴充功能會在 chrome.storage.local 保存最後一筆批次紀錄。內容包含課程 ID、來源分頁 ID、執行階段、時間、彙總數字，以及使用者貼上的成員姓名、電子郵件與逐人執行狀態。此紀錄只保留在目前 Chrome 使用者設定檔，不會使用同步儲存；使用者可直接關閉紀錄，新批次開始時也會取代舊紀錄。

成員頁的「下載完整名冊」只在管理員主動按下時執行：擴充功能在瀏覽器內把上述成員資料整理成 Excel 檔，下載到使用者自己的電腦，或複製到剪貼簿。資料只在側邊欄記憶體中暫存最多 5 分鐘（方便改用另一種方式輸出），不寫入擴充功能的儲存區；下載後的檔案由使用者自行保管與刪除。擴充功能只在本機保存使用者勾選的欄位名稱，不含成員資料。

4. 傳輸、分享與販售

擴充功能只與獲授權的 NTU COOL 服務網域以 HTTPS 交換功能所需資料。擴充功能沒有發布者伺服器、第三方分析服務或廣告服務，不會將使用者資料出售、分享或轉移給第三方。

5. 安全與使用者責任

所有受支援的網域均使用 HTTPS。擴充功能不會擴大使用者在 NTU COOL 的原有權限；每項操作仍受目前帳號權限限制。使用者應僅在已獲授權管理的課程中使用本工具，並在執行寫入或移除操作前確認預覽內容。

6. Limited Use

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

7. 政策更新與聯絡

如資料處理方式發生變更，發布者會先更新商店頁面、本政策，並依規定在擴充功能中提供顯著通知。如有隱私權問題，請透過 Chrome 線上應用程式商店商品頁所列的發布者聯絡方式聯絡。
